Stop leaking API keys, database passwords, internal tokens, and customer PII into ChatGPT, Claude, Gemini, or remote AI workflows.

PromptShield Pro is a local, zero-telemetry cybersecurity utility for developers, security engineers, and devops teams. It detects sensitive credentials and masks them with consistent pseudonyms before your data leaves your computer.

🧪 Test Before You Buy: Try the live interactive browser sandbox directly in your browser: https://lorthris.github.io/promptshield/

⭐ GitHub Repository: Inspect the repository and documentation: https://github.com/lorthris/promptshield

Key Capabilities

  • Deterministic Pseudonyms: Identical secrets receive the same pseudonym throughout the prompt (e.g. [ANTHROPIC_KEY_1]). The AI model retains full relational context and code reasoning without ever seeing your actual keys.
  • Two-Way Session Rehydration: Send masked logs or prompts to Claude or ChatGPT, then run promptshield restore on the AI response to automatically swap back your real local variables.
  • 50+ Secret Detectors + Shannon Entropy: Catches OpenAI, Anthropic, Gemini, AWS, Stripe, GitHub, Slack tokens, database connection strings, RSA private keys, JWTs, and high-entropy passwords.
  • Australian & International Identity Rules: Native algorithmic verification for Australian Tax File Numbers (ATO Mod 11), Medicare numbers, Australian mobiles, credit cards (Luhn check), and private IP blocks.
  • Automated Git Pre-Commit Hook: One-command install blocks sensitive commits before they are pushed to GitHub or GitLab.
  • System Clipboard Sanitiser: Sanitise whatever is copied to your clipboard with a single command before pasting into web browsers.
  • Offline Web Sandbox: Standalone browser-based inspection interface included (zero network connection required).
